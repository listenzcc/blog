## 引言

当电荷静止时，我们熟悉库仑场；当电荷匀速直线运动时，场通过洛伦兹变换得到；而当电荷任意加速运动时，场的完整、相对论一致的表达由 **Liénard–Wiechert 势** 给出。关键概念是**时滞（retarded time）**：观察点在时刻 $t$ 看到的场，是由电荷在更早时刻 $t_r$ 发出的信息决定的，满足光锥条件 $t - t_r = R(t_r)/c$。
这一点既是物理直觉（信息以光速传播），也是数学推导的核心。 [Wikipedia](https://en.wikipedia.org/wiki/Li%C3%A9nard%E2%80%93Wiechert_potential) [Galileo and Einstein](https://galileoandeinstein.phys.virginia.edu/Elec_Mag/2022_Lectures/EM_67_Lienard_Weichert.html)

## 理论背景

### Liénard–Wiechert 势与场的要点

* **势的形式**：标势 $\varphi(\mathbf r,t)$ 与矢势 $\mathbf A(\mathbf r,t)$ 都在滞后时间 $t_r$ 处由电荷位置与速度决定，分母包含项 $R - \mathbf v\cdot\mathbf R / c$，这反映了速度沿视线分量对场强的修正。 [Wikipedia](https://en.wikipedia.org/wiki/Li%C3%A9nard%E2%80%93Wiechert_potential)
* **电场的两部分**：电场可以分为“库仑样项”（随 $1/R^2$ 衰减，主要由瞬时位置与速度决定）和“辐射项”（随 $1/R$ 衰减，包含加速度项，负责远场辐射）。这一区分在推导与数值可视化时非常重要。 [Wake Forest Student, Faculty and Staff Web Pages](https://users.wfu.edu/natalie/s13phy712/lecturenote/lecture27/lecture27latexslides.pdf) [Kirk McDonald's Research Interests](http://kirkmcd.princeton.edu/examples/lw_potentials.pdf)
* **求导技巧**：对势求梯度与时间导数时必须考虑 $t_r$ 对空间与时间的依赖（隐函数求导），这会产生额外的因子并引入 $1 - \mathbf n\cdot\boldsymbol\beta$ 等项。 [Galileo and Einstein](https://galileoandeinstein.phys.virginia.edu/Elec_Mag/2022_Lectures/EM_67_Lienard_Weichert.html) [users.hep.manchester.ac.uk](https://users.hep.manchester.ac.uk/u/rmj/PHYS30441/Radiation%20and%20Lienard%20Wiechert%20Potentials%20Part%202.pdf)

单个运动电荷的精确解由 `Liénard–Wiechert potentials` 给出。电场可以写成下式

$$
\mathbf{E}(\mathbf{r},t) = \underbrace{\frac{q}{4\pi\varepsilon_0} \frac{\mathbf{n}-\boldsymbol{\beta}}{\gamma^2 (1-\mathbf{n}\cdot\boldsymbol{\beta})^3 R^2}}_{\text{库仑/近场}} + \underbrace{\frac{q}{4\pi\varepsilon_0 c} \frac{\mathbf{n}\times[(\mathbf{n}-\boldsymbol{\beta})\times \dot{\boldsymbol{\beta}}]} {(1-\mathbf{n}\cdot\boldsymbol{\beta})^3 R}}_{\text{辐射场}}
$$

其中的关键变量为

* $\boldsymbol{\beta} = \mathbf{v}/c$
* $\dot{\boldsymbol{\beta}} = \mathbf{a}/c$
* $\mathbf{n}$：从“延迟位置”指向观测点
* $R$：延迟距离（retarded distance）

其中的关键点是二项，分别是

* $1/R^2$代表近场，即静电样的场。
* $1/R$ 代表辐射场，即真正传播能量的场。

### 物理直观

* 观察点看到的场是电荷世界线与该观察点的后向光锥相交处的信息。速度沿视线分量会改变“信息包”的到达速率（类似多普勒效应），因此出现额外修正因子。 [Galileo and Einstein](https://galileoandeinstein.phys.virginia.edu/Elec_Mag/2022_Lectures/EM_67_Lienard_Weichert.html)

## 数值实现要点 与 着色器对应

下面把理论要点映射到 WebGL2 着色器代码中，解释每一步的物理与数值含义。

### 1. 时滞方程的数值求解

**理论**：滞后时间 $t_r$ 满足隐式方程 $t - t_r = \frac{|\mathbf r - \mathbf r_q(t_r)|}{c}$。  
**实现**：着色器中 `solve_tr` 使用固定点迭代（fixed-point iteration）：

```cpp
float tr = t;
for(int i=0;i<20;i++){
    vec3 rp = chargePos(tr);
    float R = length(r - rp);
    tr = t - R / c;
}
```

**说明与建议**：固定点迭代在轨迹平滑且速度不接近光速时通常收敛；若轨迹快速变化或接近 $c$，应改用牛顿法或混合策略并限制迭代次数与步长以保证稳定性。固定点初值可用上帧的 $t_r$ 作为热启动以加速收敛。 [Wake Forest Student, Faculty and Staff Web Pages](https://users.wfu.edu/natalie/s13phy712/lecturenote/lecture27/lecture27latexslides.pdf)

### 2. 速度与加速度的数值导数

代码用中心差分估计速度与加速度：

```cpp
vec3 rp_m = chargePos(tr - dt);
vec3 rp_p = chargePos(tr + dt);
vec3 v = (rp_p - rp_m) / (2.0 * dt);
vec3 a = (rp_p - 2.0 * rp + rp_m) / (dt * dt);
```

**说明**：中心差分在平滑轨迹上精度较好，但对噪声敏感。`dt` 需与轨迹时间尺度匹配；过大导致截断误差，过小导致舍入误差与数值不稳定。若轨迹为解析表达式，可在 CPU 端预计算解析导数并传入着色器以提高精度。

### 3. 场的表达式与数值稳定化

着色器中 `computeE` 使用了与 Liénard–Wiechert 场形式相似的结构：包含 $1/(R^2 (1-\mathbf n\cdot\beta)^3)$ 的库仑样项与包含加速度的辐射项。为了避免数值发散，代码对强度做了**压缩与对数映射**：

```cpp
float intensity = length(E);
float normIntensity = intensity / (1.0 + intensity);
float logIntensity = log(normIntensity + 1.0);
```

**说明**：对数或有界映射能把极端值压缩到可视范围，避免颜色饱和并保留细节。对于近场$R\rightarrow0$需要在物理上处理点电荷奇异性，例如引入有限尺寸核或在渲染时对非常小的 $R$ 做截断。

### 4. 多电荷叠加与相位信息

示例中叠加了两个轨迹（`chargePos` 与 `chargePos1`），并用相位 `atan(E.y,E.x)` 绘制方向信息与等相位线。叠加是线性的（电场满足叠加原理），但在可视化时要注意颜色映射与对比度调整，避免不同源的强度互相掩盖。

## 如何修改轨迹与交互建议

### 修改轨迹

在着色器中 `chargePos(float t)` 是唯一需要改动的函数。举例：把轨迹改为螺旋或抛物线：

```cpp
vec3 chargePos(float t) {
    float r = 0.4;
    float omega = 2.0;
    return vec3(r * cos(omega * t), r * sin(omega * t), 0.2 * t);
}
```

若想做更复杂的轨迹（分段、随机扰动或受力运动），建议在 CPU 端生成轨迹表（时间序列），上传为纹理或 uniform 缓冲，在着色器中按 `t_r` 查表以避免在片元着色器内做复杂运算。

### 交互与参数

* **速度标尺**：在界面上显示最大速度与加速度的刻度，避免用户设置导致数值不收敛。
* **实时调节 dt 与 迭代次数**：提供滑条控制 `dt` 与 `solve_tr` 的迭代次数，观察收敛与视觉效果。
* **切换显示模式**：强度、相位、矢量场箭头（用线渲染或纹理）与辐射/近场分量分开显示，便于物理分析。

## 数值稳定性 与 性能优化

* **避免在片元着色器中做过多迭代**：每个像素都要求解滞后时间并计算导数，代价高。可用较低分辨率的场缓存（framebuffer）做近似，再双线性放大。
* **使用纹理查表**：若轨迹已知且周期性，可把位置、速度、加速度预计算并存为 1D 纹理，片元着色器通过 `texture` 采样获得值，显著降低计算量。
* **并行与精度权衡**：在 WebGL2 中 `highp` 浮点支持有限，注意在移动设备上可能退化为 `mediump`。对关键计算（如迭代）可在 CPU 端做部分预处理。
* **奇异点处理**：对非常小的 (R) 做下限截断（例如 `R = max(R, eps)`），或用有限尺寸模型替代点电荷以避免数值爆炸。

## 物理限制 与 可扩展方向

* **相对论效应**：当前实现以 $c=1$ 并用经典 Liénard–Wiechert 形式近似。若速度接近光速，必须严格使用相对论形式并注意数值稳定性与因果性（滞后时间仍唯一）。 [Wikipedia](https://en.wikipedia.org/wiki/Li%C3%A9nard%E2%80%93Wiechert_potential) [Kirk McDonald's Research Interests](http://kirkmcd.princeton.edu/examples/lw_potentials.pdf)
* **多粒子系统**：电场线性叠加，但若考虑粒子间相互作用（动力学耦合），需要求解耦合的运动方程并处理延迟相互作用，这会显著增加复杂度。 [Kirk McDonald's Research Interests](http://kirkmcd.princeton.edu/examples/lw_potentials.pdf)
* **辐射能量与功率**：从 Liénard–Wiechert 场可以导出 Larmor 或 Liénard 的辐射功率公式，用于估计加速电荷的能量损失与辐射模式。 [Wake Forest Student, Faculty and Staff Web Pages](https://users.wfu.edu/natalie/s13phy712/lecturenote/lecture27/lecture27latexslides.pdf)

## 结论

本文把 Liénard–Wiechert 理论与一个**实时 WebGL2 可视化实现**连接起来：

* 物理上，关键在于滞后时间与速度/加速度对场的修正；
* 数值上，滞后时间求解、导数估计与奇异点处理是核心；
* 工程上，预计算、纹理查表与多分辨率策略能在保证物理意义的同时实现实时渲染。

这个可视化既能作为教学工具，帮助理解电荷运动如何通过光锥影响远处场，也能作为研究原型，用于探索不同轨迹下的辐射模式与近场结构。
